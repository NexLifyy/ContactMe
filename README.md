# Welcome & Contact Page

A sleek, responsive landing page featuring:
- **Heading**: "I am glad you are here"
- **Interactive Button**: "Click here to get my number"

## Features
- 🎨 **Modern Visuals**: Ambient animated glowing mesh, glassmorphism card, and clean typography.
- 📱 **Interactive Contact Modal**: Displays the phone number with one-click **Copy to Clipboard**, **Direct Call**, and **WhatsApp** triggers.
- 🎉 **Celebratory Confetti**: Instant delightful micro-interaction upon revealing the number.
- 🌓 **Dark & Light Mode**: Seamless theme switching with automatic system preference detection.
- ✏️ **Quick Number Customization**: Easily change the displayed number right from the UI (persisted to LocalStorage) or directly in `index.html`.

## How to View
Double-click [`index.html`](./index.html) to open it in any web browser.
